# Food Price Pressure in Malaysia

An interactive Data Visualisation 2 project exploring food price pressure, household exposure, and local production context across Malaysian states.

## Author

Ahmad Sufi Bin Aziz Shah

## Date

May 2026

## Tools

Vega-Lite, Vega-Embed, Pure.css, HTML, CSS, and JavaScript.

## Data Sources

- Primary data: Department of Statistics Malaysia datasets accessed through OpenDOSM and data.gov.my.
- Geographic data: Malaysia administrative state boundaries from geoBoundaries.
- Background geography: world-atlas country boundaries for neighbouring country and ocean context.

## Visualisation Story

The visualisation guides readers from where food price pressure is highest, to how state rankings and trends change over time, then to whether household context, crop production, and fish supply help explain affordability patterns.

## Visualisation Idioms

Choropleth map, ranked lollipop chart, bump chart, item price movement chart, indexed food basket line chart, grouped Consumer Price Index trend lines, heatmap, barcode timeline, slope chart, production map, scatter plot, connected dot plot, and a custom food security pressure profile.
